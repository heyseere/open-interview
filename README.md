# Open Interview

按下快捷键截取屏幕上的题目，AI 实时分析并流式给出解题思路和答案。窗口对屏幕分享软件隐身、不抢占焦点，语音转录完全在本地运行。

---

## 功能特性

- **截屏解题**：快捷键抓取屏幕内容发送给视觉大模型，流式展示解答；支持追加截图、追问，保持对话上下文连续
- **场景化提示词**：预置「解算法题」「英语考试」「通用问答」三个场景，可编辑、可自建，适配任意题型
- **本地语音转录**：基于 whisper.cpp（`whisper-cli` + ggml 模型），实时把电脑播放的声音转为文字，音频不出本机、无需任何在线语音 API；一键配置自动准备引擎与模型，支持静音自动提交（VAD）
- **隐身模式**（默认关闭）：一个开关控制三件事——对屏幕共享/录屏不可见、隐藏 macOS Dock 图标、截图不写入磁盘；顶部按钮或设置页均可开关
- **鼠标穿透**：窗口对鼠标隐身，点击落到窗口背后的页面；悬停工具栏可随时恢复
- **紧凑提词面板**：正方形小窗只保留答案与转录行，可拖拽缩放，适合窄屏跟读
- **悬停工具栏**：底部悬浮三段式工具栏（转录控制 / 截图控制 / 生成控制），悬停即触发，暂不可用的按钮自动置灰
- **隐私与安全**：API Key 通过系统安全存储（Electron safeStorage）加密保存；模型列表自动拉取；内置权限中心查看并请求屏幕录制 / 麦克风权限
- **中英双语界面**：设置页一键切换

## 快速开始

### 1. 安装依赖

需要 Node.js 环境（未安装请先安装 [Node.js](https://nodejs.org/zh-cn/download)）。

```bash
npm install
```

### 2. 启动 / 构建

```bash
npm run dev          # 开发模式
npm run build:mac    # 构建 macOS 安装包
npm run build:win    # 构建 Windows 安装包
```

### 3. 配置 AI

启动后进入「设置」页，填写 `API Base URL` 和 `API Key`（如国内的 [硅基流动](https://cloud.siliconflow.cn/i/SG8C0772) 或国外的 [OpenRouter](https://openrouter.ai/)）。

也可以在项目根目录创建 `.env` 预配置，启动时自动读取为默认值：

```env
API_BASE_URL="https://openrouter.ai/api/v1"
API_KEY="sk-..."
```

### 4.（可选）本地语音转录

首次使用前在设置页「语音转录」点击**一键配置**：

- Windows：自动下载 whisper.cpp 预编译包
- macOS：通过 Homebrew 安装（无 Homebrew 时自动本地编译）

模型按需下载（默认 `base`，识别语言默认自动检测），之后完全离线可用。按快捷键开始转录，再次按下停止并把文本提交给 AI。分段时长 3–15 秒可调；开启「静音自动提交」后，说话停顿即自动发送。

### 5.（可选）系统权限

macOS 首次截图 / 转录时会自动弹出权限请求。也可以在 **设置 → 语音转录 → 权限中心** 查看屏幕录制与麦克风的当前状态、手动重新请求或直达系统设置。

## 关于隐身能力的说明

隐身功能适配市面上大部分会议软件（如腾讯会议等），但少量软件和浏览器可能无法正常隐身。**使用前请自行测试，本项目不承担任何责任。**

**能力边界**：

- 应用通过系统接口对屏幕捕获隐藏自身窗口，并持续重申该属性；但这只能防御"合规读取屏幕画面"的软件，**操作系统级的录屏工具或内核级键盘记录器不在任何应用的防御范围内**
- 建议的自查方式：在腾讯会议 / 浏览器标签共享中开启共享，观察对方画面是否出现本应用窗口
- 所有 API Key 通过系统钥匙串加密存储，不会明文落盘；语音转录音频仅在内存中分块处理，不写入磁盘
