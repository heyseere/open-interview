# Open Interview

按下快捷键截取屏幕上的题目，AI 实时分析并流式给出解题思路和答案。窗口可对屏幕共享/录屏**完全隐身**，开启隐身后还能悬浮在其他应用的全屏窗口之上；语音转录完全在**本地**运行，音频不出本机。

支持 **macOS（Apple Silicon）** 与 **Windows 10/11**。

---

## 功能特性

### 截屏解题

- 快捷键抓取屏幕内容，视觉大模型流式输出解答，边生成边显示
- **追加截图**延续同一对话：多题连问、长题目分屏截取，上下文不丢
- **追问**、停止生成、失败一键重试、随时开启新会话
- **场景化提示词**：预置「解算法题」「英语考试」「通用问答」，可编辑、可自建，适配任意题型

### 本地语音转录

- 基于 whisper.cpp（`whisper-cli` + ggml 模型），**无需任何在线语音 API**，音频仅在内存中分块处理、不落盘
- **一键配置**：自动下载引擎与模型（Windows 用预编译包；macOS 优先 Homebrew，无 Homebrew 时本地编译），全程可视化进度、可取消
- 模型 6 档可选（tiny ~ large-v3-turbo），识别语言自动检测 / 中文 / 英文
- 分段时长 3–15 秒可调；**静音自动提交**（VAD）：说完停顿即自动把文本发给 AI
- 再次按快捷键停止并提交转录文本，可直接语音提问

### 隐身与窗口控制

- **隐身模式**（默认关闭）：一个开关控制全部姿态——对屏幕共享/录屏不可见、隐藏 Dock/任务栏图标、截图不写入磁盘；开启后窗口悬浮于其他应用的全屏窗口之上
- **鼠标穿透**：窗口对鼠标隐身，点击直达背后页面；悬停底部工具栏或按快捷键随时恢复
- **Mini/紧凑提词面板**：正方形小窗只保留答案与转录行，可拖拽缩放，适合贴边跟读
- **悬停工具栏**：转录 / 截图 / 生成三段式控制，指针悬停即触发（时长可调），暂不可用的按钮自动置灰
- 键盘翻页、按方向键移动窗口；窗口隐藏后快捷键唤回

### 隐私与配置

- API Key 通过系统安全存储（Electron safeStorage）**加密保存**，不落明文
- 任意 **OpenAI 兼容 API** 均可使用（硅基流动、OpenRouter 等），模型列表自动拉取，也可手动填写
- 截图可选保存到本地目录（隐身模式下自动停用写入）
- 内置**权限中心**：查看屏幕录制 / 麦克风授权状态、手动重新请求、直达系统设置
- 中英双语界面，一键切换

## 典型场景

### 在线编程面试（共享屏幕写题）

1. 设置页配好 AI 服务，打开隐身模式
2. 面试官在共享屏幕中给出题目 → 按截图快捷键，答案流式出现在悬浮窗里
3. 思路细节用追问继续挖；换新题追加截图，不用重新解释背景
4. 听不清面试官的语音？开语音转录（Windows 采系统声音，macOS 采麦克风）

### 在线笔试 / 机试（全屏答题页）

1. 开启隐身模式，`Alt+L` 切到紧凑面板，拖到答题页角落
2. 窗口悬浮在**全屏**答题页之上，而共享/录屏画面里看不到它
3. `Alt+M` 鼠标穿透，点击直达答题页；需要操作悬浮窗时悬停工具栏唤回
4. 一题一截图，流式跟读答案

### 外语 / 文字类考试

1. 场景切到「英语考试」，提示词可按题型自行调整
2. 长篇阅读分屏追加截图，一次把全文喂给 AI
3. 作文、翻译可直接打字追问，或用语音转录口述题目

### 日常通用问答

- 「通用问答」场景 + 截图 = 随手可用的屏幕问答助手；不开隐身就是一个普通窗口

## 各平台使用说明

### macOS

- **权限按需申请**：首次截图时弹「屏幕录制」、首次转录时弹「麦克风」授权，都是应用内触发，无需终端或手动操作；「设置 → 权限中心」可随时查看状态、重新请求或直达系统设置
- **转录默认采集麦克风**；若要转录系统播放的声音（如会议中对方的语音），需自行安装 [BlackHole](https://existential.audio/) 虚拟声卡并选为输入设备——应用帮助页 FAQ 有完整步骤
- 隐身模式会隐藏 Dock 图标；macOS 不支持应用内自动更新，升级需手动下载新版本

### Windows

- **转录默认采集系统音频**（电脑播放什么就转什么），也可在设置中改选麦克风设备
- 快捷键默认 `Ctrl` 系；自定义的 `Alt` 快捷键会同时注册 `Ctrl+Alt` 变体以规避冲突
- 支持应用内自动更新

### 通用

- 全部快捷键均可在设置页改键；鼠标**侧键**（中键 / 前进 / 后退）也可绑定为任意动作（指针位于窗口上时生效）
- 隐身模式对主流会议/共享软件（腾讯会议等）有效，但个别软件可能例外——**使用前请自行实测**

## 下载安装

从 [GitHub Releases](https://github.com/heyseere/open-interview/releases) 下载：

| 平台 | 文件 |
| ---- | ---- |
| macOS（Apple Silicon） | `open-interview-1.0.0.dmg` 或 `open-interview-1.0.0-arm64-mac.zip` |
| Windows 10/11 | `open-interview-1.0.0-setup.exe` |

首次使用：

1. 进入「设置」页，填写 API Base URL 与 API Key（如 [硅基流动](https://cloud.siliconflow.cn/i/SG8C0772)、[OpenRouter](https://openrouter.ai/) 等任意 OpenAI 兼容服务），选择模型
2. （可选）「语音转录」区点击**一键配置**，自动准备 whisper.cpp 引擎与模型，之后完全离线可用
3. 也可以在项目根目录创建 `.env` 预配置，启动时自动读取为默认值：

   ```env
   API_BASE_URL="https://openrouter.ai/api/v1"
   API_KEY="sk-..."
   MODEL="gpt-5-mini"
   ```

## 默认快捷键

| 功能 | macOS | Windows |
| ---- | ----- | ------- |
| 截图并解题（新会话） | `Alt+Enter` | `Ctrl+Enter` |
| 追加截图 | `Alt+Shift+Enter` | `Ctrl+Shift+Enter` |
| 停止生成 | `Alt+.` | `Ctrl+.` |
| 追问 | `Alt+F` | `Ctrl+F` |
| 语音转录 开/停+提交 | `Alt+T` | `Ctrl+T` |
| 清除转录文本 | `Alt+Shift+T` | `Ctrl+Shift+T` |
| 隐藏/显示窗口 | `Alt+H` | `Ctrl+H` |
| 鼠标穿透 | `Alt+M` | `Ctrl+M` |
| Mini/紧凑面板 | `Alt+L` | `Ctrl+L` |
| 上/下翻页 | `Cmd+J / Cmd+K` | `Ctrl+J / Ctrl+K` |
| 移动窗口 | `Cmd+方向键` | `Ctrl+方向键` |

所有快捷键均可在设置页自定义，并可绑定鼠标侧键。

## 关于隐身能力的说明

隐身功能适配市面上大部分会议软件（如腾讯会议等），但少量软件和浏览器可能无法正常隐身。**使用前请自行测试，本项目不承担任何责任。**

**能力边界**：

- 应用通过系统接口对屏幕捕获隐藏自身窗口，并持续重申该属性；但这只能防御“合规读取屏幕画面”的软件，**操作系统级的录屏工具或内核级键盘记录器不在任何应用的防御范围内**
- 建议的自查方式：在腾讯会议 / 浏览器标签共享中开启共享，观察对方画面是否出现本应用窗口
- 所有 API Key 通过系统钥匙串加密存储，不会明文落盘；语音转录音频仅在内存中分块处理，不写入磁盘
